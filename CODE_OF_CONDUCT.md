# Code of Conduct

[English](CODE_OF_CONDUCT.md) | [简体中文](CODE_OF_CONDUCT.zh-CN.md)

We are committed to an open, welcoming, and respectful community. Discuss code, data, licenses, and results constructively and assume good faith.

Unacceptable behavior includes harassment, discrimination, threats, personal attacks, publishing private information, submitting unauthorized copyrighted material, or malicious disruption of project discussions.

Maintainers may remove inappropriate content, close discussions, or restrict participation when this code is violated. Report sensitive security or privacy issues privately instead of disclosing them in public discussions.
